# Public Code OSS candidate declarations

These declarations are copied from microsoft/vscode at commit
`df53daabb18cd157bdb08c7f01c34df936cf12f4` (public 1.132.0 candidate).
They are **not confirmed to be the original custom ShunCode carrier declarations**.

`provenance.json` records each upstream path, Git blob SHA, SHA-256 and byte count.
`LICENSE.txt` is the upstream MIT license; original copyright headers are retained.
No upstream application build or Electron binary is included here.

The diagnostic tool consumes eight declaration files. Missing custom host fields
are reported as errors, not hidden by a permissive replacement declaration.
See `docs/LINKED_EXTENSION_BUILD.md` for the actual diagnostic result and limits.
