# Windows 本地分析助手

这个工具只读取安装包并生成 JSON 报告，不安装、不运行包内程序、不联网、不上传数据，也不修改原始安装包。

## 使用步骤

1. 将 `windows-inspection-kit.zip` 解压到一个文件夹，**不要在压缩包内直接运行**。
2. 电脑需要 Python 3.10 或更高版本。若没有，请从 https://www.python.org/downloads/windows/ 安装正式版本，保留默认的 Tcl/Tk 与 Python Launcher 组件。Python 3.14+ 还内置支持 zstd 压缩包。
3. 双击 `inspect-windows.cmd`。
4. 在文件选择框中选中你保留的 **Windows `.exe` / `.msi` 安装包**。当前主线只需要 Windows 包；工具仍保留 Linux `.deb` 分析能力，但不要求提供它。
5. 选择一个保存报告的文件夹。分析期间请等待，不要关闭黑色窗口。
6. 出现完成提示后，将生成的 `.inspection.json` 文件发给助手。**不用发送原始安装包。** 若失败，把报错信息发来即可。

如果 Windows 提示拦截未知脚本，不要关闭全局安全防护。可以先查看这两个纯文本脚本，或将提示内容发给助手。

## 能做什么、不能做什么

- Linux Debian 包：记录 SHA-256、版本线索、依赖名称、原生模块路径、source map 内嵌源码数量、ASAR 目录线索。
- 旧 Windows 安装包：本阶段只记录文件名、大小和 SHA-256，**不解包 Windows 安装器**。这些信息用于下一步选择合适工具。
- 不恢复源码，不构建新版本，不自动判断两个版本能否兼容。
- 不记录电脑上的绝对路径、源码正文或完整配置；报告仍可能包含包内文件名、依赖名和产品标识，分享前可用记事本检查。
- 报告列表有数量限制，通常远小于原包；上限截断会在报告内注明。
- 如果包采用 zstd 且 Python 版本过旧，工具会提示使用 Python 3.14+ 或安装可选 `zstandard` 模块，不会自行安装。

## 验证状态

解析逻辑已在 Linux 环境使用模拟 `.deb` / ASAR / Windows 文件测试通过；尚未在 Windows 实机运行，也尚未拿到真实安装包验证。遇到问题由助手根据错误继续修复。
